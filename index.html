Kyogas

As of right now, our main project is Kyogas

What is Kyogas?

Kyogas is a minimalistic markup language with static typing that I made because I didn't have anything better to do. And because JSON is too verbose and I despise YAML using indentation for everything.

- Wernasho's description of Kyogas


Here is an example of Kyogas's syntax: 


str name: player
byte lvl: 5
uint gold: 358
uint xp: 44
byte hp: 100
byte max-hp: 100
byte defense: 4
byte attack: 45
